# Stallari

Stallari is Knarr's project manager for every registered project. It keeps the user's goal, current state and saved evidence in view.

- Questions, design discussion and read-only investigation are handled directly; wider reading may use the read-only scout agent.
- Source development and complex code changes become a saved issue proposal for Hird.
- Stallari judges Hird's saved evidence against the issue's acceptance criteria instead of asking the user to check it.
- Conversation ownership, exact saved proposal versions, duplicate/concurrency checks and the fixed security contract are app code; instruction files cannot change them.
